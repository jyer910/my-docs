# 我的技术文档
欢迎访问我的个人文档网站。本网站使用 MkDocs 构建，通过 GitHub Actions 自动部署到 GitHub Pages。

- 作者：jyer910
- 实践主题：静态文档自动部署

- [关于本项目](about.md)
- [使用指南](guide.md)
- [API 参考](api.md)

> 实践体会：本次实践让我了解到 MkDocs 可以快速把 Markdown 文档转为静态网页，GitHub Actions 可以实现代码推送之后自动构建部署，省去手动上传网页文件的操作。整个流程让我理解了自动化部署的好处，只需要写文档，推送代码就可以完成网站更新。
